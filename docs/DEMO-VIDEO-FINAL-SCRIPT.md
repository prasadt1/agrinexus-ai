**How to actually find a usable track (sites don’t use our poetic labels):**

1. **[YouTube Audio Library](https://studio.youtube.com/channel/UC/music)** (needs YT Studio login): open **Audio Library** → set **Duration** to **≥3:00** → open **Filters** → **Mood:** *Calm* or *Dark* (for gravitas) or *Bright* (for ending) → **Genre:** *Ambient*, *Cinematic*, or *Classical* → pick something **without vocals**. Preview with **video playing** — if it fights your voice, skip it.
2. **[Pixabay Music](https://pixabay.com/music/)**: use **Genre** sidebar — **Acoustic**, **Ambient**, **Cinematic** — not the main Google search bar. Sort by **duration**; download MP3.
3. **CapCut** → **Audio** → **Music**: categories like **Calm** / **Inspiring** — fastest if you already edit there; check **license** in app help for commercial/competition use.
4. **[Incompetech](https://incompetech.com/music/royalty-free/music.html)**: click **Genre** → *Soundtrack* or *Ambient* → short loops; credit per site rules.

**Avoid:** vocals, loud drums, catchy melody under English speech. **EQ** (optional): light **high-pass ~200 Hz** on bed so low end doesn’t muddy VO.
